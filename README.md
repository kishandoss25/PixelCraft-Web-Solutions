# PixelCraft — Web Development Internship Project

A responsive multi-page website project based on the topics in the uploaded Web Development internship report. It demonstrates HTML structure, CSS styling and responsive layouts, JavaScript interaction, navigation, UI/UX principles, accessibility basics, SEO metadata, project filtering, and client-side form validation.

## Pages
- `index.html` — Home page, services overview, process and call to action
- `about.html` — Project philosophy and design principles
- `services.html` — Web design, development, optimization, and content/data topics
- `projects.html` — Three fictional concept cards with working category filters
- `contact.html` — Contact form demo with validation and feedback

## Technologies
- HTML5
- CSS3 (Grid, Flexbox, media queries, responsive/mobile-first layout)
- Vanilla JavaScript (mobile menu, filtering, form validation)

## Run the project
1. Extract `webdev_internship_project.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to open it in a browser, or open the folder in Visual Studio Code and use Live Server.

No build step or package installation is required. Google Fonts are loaded from an external service when internet access is available; system fallbacks are included.

## Notes
- The contact form is a front-end demonstration only. It does not submit data to a server or store it.
- Project names and visuals are fictional demo concepts.
- This project implements a selected practical subset of the report. JDBC, CMS platforms, analytics integrations, and server-side security require separate back-end/service configuration and are not represented as functioning integrations here.
